# Grade Calculator

A console program for teachers. It reads a student's name and 5 scores, then shows the average and the grade. The teacher can enter many students in one run and see the class average at the end.

## Requirements

- The program shall prompt for a student's name before asking for any scores.
- The program shall accept only whole-number scores from 0 to 100 and repeat the prompt for the same score if the value is invalid.
- The program shall calculate each student's average as a decimal number and print it with one digit after the point.
- The program shall assign grade A, B, C or F according to the grading scale and print it on the same line as the name and average.
- The program shall count the students and, after the teacher types "end", print the number of students and the class average, or "No students entered" if there were none.

## Grading scale

| Grade | Average |
|-------|---------|
| A | 90 - 100 |
| B | 75 - 89.99 |
| C | 60 - 74.99 |
| F | below 60 |
